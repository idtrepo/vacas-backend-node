# Sistema de monitoreo y gestion de ganado

Sistema que permite el monitoreo en tiempo real del ganado, administrar sus datos y ubicacion

## Instrucciones de instalacion

>1. Ejecutar el comando **pnpm i** o **pnpm install**
>
>2. Crear un archivo **.env** con la siguiente estructura
>    - PORT= **PUERTO DE TU ELECCION**
>
>3. Ejecutar el comando **pnpm start**
